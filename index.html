apk-uploader

apk-uploader は、開発者本人の PC でビルドされた Android アプリ（APK ファイル）を、開発者本人の Google ドライブへ自動でアップロードするための個人用ツールです。一般には公開・配布していません。

プライバシーポリシー

  • 本ツールは Google ドライブ API を、開発者本人のドライブ内の指定フォルダへファイルをアップロード・更新する目的にのみ使用します。
  • 取得した認証情報やファイルは開発者本人の PC 上にのみ保存され、第三者へ送信・共有・販売することはありません。
  • Google ユーザーデータを広告、分析、または AI モデルの学習に使用することはありません。
  • 本ツールによる Google ドライブ API の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
  • アクセス権は Google アカウントの権限設定 からいつでも取り消せます。
